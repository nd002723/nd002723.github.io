# /archive/

这里存放 2018 年前后旧版网站留下的静态资源，已经**没有任何页面引用**，仅作存档。

| 路径 | 原用途 |
| --- | --- |
| `wp-json` | 旧 WordPress 站点的 REST 接口导出 |
| `js/jquery*.js`、`js/notie.min.js`、`js/plus_prism.js` | 旧首页 / 404 页的交互库 |
| `js/hm.js` | 旧站统计脚本 |
| `js/404.js` | 旧 404 页脚本 |
| `css/style.css`、`css/loader.min.css` | 旧版首页样式与加载动画 |
| `css/404-style.css`、`css/frontend.css`、`css/poi.css` | 旧 404 / 播放器样式 |
| `img/head.jpg`、`img/bianping.png` | 旧版首页头图与项目缩略图 |
| `video/*.mp4`、`video/*.mov`、`video/background.webp` | 旧版首页背景视频素材 |

现行站点只使用：`css/webf-ui.css`、`css/site.css`、`js/site.js`、`js/bgm.js`、`img/site-icon.svg`、`img/404.png`、`img` 里的三位成员头像，以及 `media/404.mp3`。
