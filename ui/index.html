UI 组件

整站页面都用这一套组件。实现文件是 css/webf-ui.css，取自 Nextra 4 + Tailwind CSS 4 的 nextjs-nextra-starter 设计系统，外观与 openwebf.com 一致。子项目只要 <link href="/css/webf-ui.css"> 就能复用。

设计令牌

颜色、圆角、字体由 CSS 变量下发，[data-theme="dark"] 时整套自动切换。

变量浅色深色用途
--nb-backgroundhsl(0 0% 100%)hsl(0 0% 3.9%)页面底色
--nb-foregroundhsl(0 0% 3.9%)hsl(0 0% 98%)正文
--nb-primaryhsl(221.2 83.2% 53.3%)hsl(217.2 91.2% 59.8%)主按钮 / 链接
--nb-muted-foregroundhsl(215.4 16.3% 46.9%)hsl(215 20.2% 65.1%)次级文字
--nb-borderhsl(0 0% 89.8%)hsl(0 0% 14.9%)描边
--nb-radius.6rem（lg +2px，sm -2px）圆角
--nb-nav-h64px导航高度
primary secondary muted destructive warning background

手风琴 Accordion

点击展开，箭头旋转 180°，对应 ui/accordion.tsx。

页面是怎么组织的？
所有页面共用 css/webf-ui.css 与 css/site.css，改一份全站同步。
子项目怎么接入？
引入同一个主站的 CSS / JS 路径即可，功能代码保持原样。
<details class="nb-accordion__item">
  <summary class="nb-accordion__trigger">标题</summary>
  <div class="nb-accordion__panel">内容</div>
</details>

代码块 Code

带复制按钮；nb-code--wrap 用于长行折行。

npm create next-app --template nextra

行内代码：css/webf-ui.css、data-theme="dark"。

<div class="nb-code">
  <pre>你的代码</pre>
  <button class="nb-code__copy" data-copy="#id">复制</button>
</div>

步骤 Steps

用于「怎么用」类说明，序号圆点带底色与描边。

  1. 引入样式
    页面头部 link css/webf-ui.css 与 css/site.css。
  2. 套根类
    给 body 加 class="nb"。
  3. 拼组件
    按本页例子组合 nb-btn / nb-card 等。
<ol class="nb-steps">
  <li><span class="nb-steps__title">第一步</span> 说明</li>
</ol>
